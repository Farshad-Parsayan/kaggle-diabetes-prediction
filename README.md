# Kaggle Diabetes Prediction

This repository contains the Python code developed for a machine learning competition focused on predicting diabetes status using demographic, behavioral, and clinical variables.

## Competition Outcome

- Achieved a Top 10 ranking on the final competition leaderboard.
- Developed and evaluated multiple machine learning models and ensemble approaches.
- Optimized classification thresholds to maximize predictive performance.

## Project Overview

The objective of this project was to develop accurate predictive models for identifying individuals with diabetes using participant-level data.

The workflow emphasized data preprocessing, feature engineering, model selection, hyperparameter tuning, cross-validation, and ensemble learning.

## Analytical Workflow

### Data Preparation

- Data quality assessment
- Missing value handling
- Categorical variable encoding
- Feature engineering
- Data partitioning
- Feature scaling where appropriate

### Baseline Models

The following baseline algorithms were evaluated:

- Logistic Regression
- Ridge Regression
- Random Forest

### Gradient Boosting Models

Advanced machine learning models were developed and optimized, including:

- XGBoost
- CatBoost

Hyperparameters were tuned using cross-validation and grid search to maximize predictive performance.

### Ensemble Learning

Predictions from multiple models were combined through weighted ensemble techniques.

The ensemble approach improved overall performance compared with individual models and produced the final competition submission.

### Threshold Optimization

Classification thresholds were systematically evaluated to identify the probability cutoff that maximized predictive accuracy.

## Model Evaluation

Model performance was assessed using:

- Cross-validation
- Accuracy
- Classification threshold optimization
- Leaderboard performance
